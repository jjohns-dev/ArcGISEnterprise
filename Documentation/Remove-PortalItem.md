# Remove-PortalItem

## SYNOPSIS
Delete Portal Item

## SYNTAX

```
Remove-PortalItem [[-UserName] <String>] [-ItemId] <String> [[-Force] <Boolean>] [-Context] <Uri>
 [-Token] <String> [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Delete Portal Item.
Use this to delete Hosted Feature Services.
