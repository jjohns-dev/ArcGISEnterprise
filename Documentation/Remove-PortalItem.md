# Remove-PortalItem

## SYNOPSIS

Delete Portal Item

## SYNTAX

### __AllParameterSets

```
Remove-PortalItem [[-UserName] <string>] [-ItemId] <string> [[-Force] <bool>] [-Context] <uri>
 [-Token] <string> [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Delete Portal Item.
Use this to delete Hosted Feature Services.

### EXAMPLE 1
