# Set-PortalConnection

## SYNOPSIS

Set default Portal for ArcGIS connection parameters

## SYNTAX

### __AllParameterSets

```
Set-PortalConnection [-Context] <uri> [-Token] <string> [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Set default Portal for ArcGIS connection parameters for subsequent cmdlet calls.

### EXAMPLE 1

Set-PortalConnection
