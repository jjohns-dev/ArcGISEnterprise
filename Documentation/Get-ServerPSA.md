# Get-ServerPSA

## SYNOPSIS

Get Portal user

## SYNTAX

### __AllParameterSets

```
Get-ServerPSA [[-Referer] <string>] [-Context] <uri> [-Token] <string> [-SkipCertificateCheck]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Get Portal user

## EXAMPLES

### EXAMPLE 1

Get-ServerPSA -Context 'https://arcgis.com/arcgis' -Token $token
Get PSA user from Server
