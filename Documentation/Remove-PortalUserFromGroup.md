# Remove-PortalUserFromGroup

## SYNOPSIS

Remove Portal user from group

## SYNTAX

### __AllParameterSets

```
Remove-PortalUserFromGroup [-GroupID] <string> [-UserName] <string[]> [-Context] <uri>
 [-Token] <string> [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Remove Portal user or manager from group

## EXAMPLES

### EXAMPLE 1

Remove-PortalUserFromGroup -GroupId $gid -UserName 'jsmith' @commonParams
Remove user 'jsmith' from group
