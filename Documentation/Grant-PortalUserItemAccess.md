# Grant-PortalUserItemAccess

## SYNOPSIS

Short description

## SYNTAX

### _grp (Default)

```
Grant-PortalUserItemAccess -ItemId <string[]> -GroupId <string[]> -Context <uri> -Token <string>
 [-UserName <string>] [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### _ery

```
Grant-PortalUserItemAccess -ItemId <string[]> -Everyone -Context <uri> -Token <string>
 [-UserName <string>] [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### _org

```
Grant-PortalUserItemAccess -ItemId <string[]> -Org -Context <uri> -Token <string>
 [-UserName <string>] [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Long description

## EXAMPLES

### EXAMPLE 1

Grant-PortalUserItemAccess -ItemId $iId -GroupId $myGroup.id @commonParams
Shares the current user's Portal item with ID $iId to the group with ID $myGroup.id
