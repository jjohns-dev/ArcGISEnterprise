# Write-PortalUserItem

## SYNOPSIS

Upload file item to Portal for ArcGIS

## SYNTAX

### __AllParameterSets

```
Write-PortalUserItem [[-UserName] <string>] [-FilePath] <string> [[-Title] <string>]
 [[-Description] <string>] [[-Snippet] <string>] [[-Tag] <string[]>] [[-TypeKeyword] <string[]>]
 [-Context] <uri> [-Token] <string> [-SkipCertificateCheck] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Upload file item to Portal for ArcGIS

## EXAMPLES

### EXAMPLE 1

Write-PortalUserItem -FilePath C:\Data.xlsx @commonParams
Uploads Data.xlsx as a Portal item for the current user
