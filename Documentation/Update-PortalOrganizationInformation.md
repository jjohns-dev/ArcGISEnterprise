# Update-PortalOrganizationInformation

## SYNOPSIS

Set Portal setting.

## SYNTAX

### __AllParameterSets

```
Update-PortalOrganizationInformation [[-DisableEditing] <bool>] [[-MaxTokenExpiration] <int>]
 [[-Origin] <string[]>] [[-SharePublicly] <bool>] [[-PortalId] <string>] [-Context] <uri>
 [-Token] <string> [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

- Update-PortalOrgInfo

## DESCRIPTION

Set or configure setting in Portal for ArcGIS sharing REST API.

## EXAMPLES

### EXAMPLE 1

Update-PortalOrganizationInformation @cmnParams -MaxTokenExpiration 1440
Set the maximum validity in minutes of both OAuth and nonOAuth tokens issued for users of the organization to 1440 minutes (24 hours).

### EXAMPLE 2

Update-PortalOrganizationInformation @cmnParams -Origin 'https://arcgis.com', 'https://test.com'
Sets the allowed origins property to 'https://arcgis.com,https://test.com'

### EXAMPLE 3

Update-PortalOrganizationInformation @cmnParams -SharePublicly $false -DisableEditing $true
Disables the public sharing of Portal content and Portal User Profile editing
