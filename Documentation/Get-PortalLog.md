# Get-PortalLog

## SYNOPSIS

Get Portal for ArcGIS logs

## SYNTAX

### __AllParameterSets

```
Get-PortalLog [[-Level] <string>] [[-StartTime] <datetime>] [[-EndTime] <datetime>]
 [[-Code] <string[]>] [[-UserName] <string[]>] [-Context] <uri> [-Token] <string>
 [-SkipCertificateCheck] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Get Portal for ArcGIS logs by using the logs query endpoint

## EXAMPLES

### EXAMPLE 1

Get-PortalLog @commonParams -EndTime (Get-Date).AddDays(-7)
Get all portal logs from the last 7 days
