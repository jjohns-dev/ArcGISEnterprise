# Get-ServerSystemProperty

## SYNOPSIS

Get the system properties of the ArcGIS Server.

## SYNTAX

### __AllParameterSets

```
Get-ServerSystemProperty [-Context] <uri> [-Token] <string> [-SkipCertificateCheck]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

This function retrieves the system properties of the server using the ArcGIS REST API.

## EXAMPLES

### EXAMPLE 1

Get-ServerSystemProperty
Get the system properties of the ArcGIS Server.
