# Set-PortalDefaultUserLicenseType

## SYNOPSIS

Set the default User License Type in Portal

## SYNTAX

### __AllParameterSets

```
Set-PortalDefaultUserLicenseType [[-PortalId] <string>] [[-UserLicenseType] <string>]
 [-Context] <uri> [-Token] <string> [-SkipCertificateCheck] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Set the default User License Type in Portal

## EXAMPLES

### EXAMPLE 1

Set-PortalDefaultUserLicenseType -UserLicenseType 'viewerUT'
Sets the default default user license type to 'viewerUT'
