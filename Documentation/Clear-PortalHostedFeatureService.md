# Clear-PortalHostedFeatureService

## SYNOPSIS
Clear Portal Hosted Feature Service

## SYNTAX

```
Clear-PortalHostedFeatureService [-ServiceName] <String> [-Layer] <Int32> [-Context] <Uri> [-Token] <String>
 [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Clear or purge all items from a table in a Hosted Feature Service Layer

## EXAMPLES

### EXAMPLE 1
```
Clear-PortalHostedFeatureService @commonParams -ServiceName dashboard -Layer 0
Clear or purge all data from the "dashboard" Hosted Feature Service layer 0
```
