# Remove-ServerService

## SYNOPSIS

Delete Feature Service from ArcGIS Server

## SYNTAX

### __AllParameterSets

```
Remove-ServerService [-ServiceName] <string> [[-Folder] <string>] [-Type] <string> [-Context] <uri>
 [-Token] <string> [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Delete Feature Service from ArcGIS Server (DO NOT use this to delete a Hosted Feature Service)

## EXAMPLES

### EXAMPLE 1

Remove-ServerService
