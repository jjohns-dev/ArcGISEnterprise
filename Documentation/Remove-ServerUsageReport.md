# Remove-ServerUsageReport

## SYNOPSIS

Delete usage report

## SYNTAX

### __AllParameterSets

```
Remove-ServerUsageReport [-ReportName] <string> [-Context] <uri> [-Token] <string>
 [-SkipCertificateCheck] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Permanently deletes the usage report.

## EXAMPLES

### EXAMPLE 1

Remove-ServerUsageReport @cmnParams -ReportName 'Test'
Deletes the 'Test' usage report.
