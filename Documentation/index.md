# ArcGISEnterprise

PowerShell module for ArcGIS Enterprise REST API. Includes functions for both
ArcGIS Server and Portal for ArcGIS.

See the top-level [README.md](../README.md) for install + quickstart.

## Per-function reference

The per-function pages in this folder (`<Function-Name>.md`) are autogenerated
from each function's comment-based help by `Microsoft.PowerShell.PlatyPS` (v2
schema). Do not hand-edit them -- changes will be overwritten on the next
regeneration. To regenerate after changing a function's parameter signature
or comment-based help:

```powershell
.\Build\build.ps1 -TaskList GenerateDocs
```

The function-to-API-endpoint table below is hand-curated; each function name
links to its generated per-function page.

## Function Naming

Like all PowerShell functions and cmdlets, the functions in this module follow the `Verb` `-` `Noun` scheme.
Each `Noun` will start with the ArcGIS Enterprise component the function should be executaged against.
For example, to use `Get-PortalRoleList` pass a Portal for ArcGIS URI argument in the `-Context` parameter.
Or, as another example, pass an ArcGIS Server URI argument to the `-Context` parameter for `Set-ServerAllowedOrigin`
to set/update the allowed origins property in ArcGIS Server.
